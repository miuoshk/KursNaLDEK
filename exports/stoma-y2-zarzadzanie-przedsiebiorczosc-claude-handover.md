## 4. Konwencja ID pytań

```
{prefiks}-{nr_tematu}-{NNN}
```

| Przedmiot        | Przykład `questions.id` | `topic_id` |
|------------------|-------------------------|------------|
| Zarządzanie      | `zar-01-001`            | `ZAR-01`   |
| Zarządzanie      | `zar-07-014`            | `ZAR-07`   |
| Przedsiębiorczość| `prz-03-002`            | `PRZ-03`   |
| Przedsiębiorczość| `prz-30-010`            | `PRZ-30`   |

- Numer tematu w ID pytania: **2 cyfry** (`01`, `07`, `30`).
- Numer pytania: **3 cyfry z zerami** (`001`, `014`).
- `question_type`: `single_choice` (domyślnie).
- `options`: JSONB, 5 opcji `a`–`e`.
- `is_active`: `true`.
- `theme_label` / `subtheme_label`: opcjonalne (brak kontrolowanej listy dla tych przedmiotów — można `NULL` lub wolny tekst).
- `batch_label`: np. `e_zar_2026/1`, `e_prz_2026/1` albo `NULL`.

## 5. Jak uploadować pytania do Supabase

### Krok 1 — wygeneruj SQL batch

Wklej do Supabase SQL Editor (Run):

```sql
-- ============================================================
-- BATCH: e_zar_2026/1 · stoma-zarzadzanie · ZAR-01
-- ============================================================

INSERT INTO public.questions
  (id, topic_id, text, options, correct_option_id, explanation, batch_label)
VALUES

('zar-01-001', 'ZAR-01',
 'Treść pytania…',
 '[
   {"id":"a","text":"Opcja A"},
   {"id":"b","text":"Opcja B"},
   {"id":"c","text":"Opcja C"},
   {"id":"d","text":"Opcja D"},
   {"id":"e","text":"Opcja E"}
 ]'::jsonb,
 'b',
 'Wyjaśnienie poprawnej odpowiedzi (2–5 zdań).',
 'e_zar_2026/1');

-- Ostatni rekord w VALUES kończy się `);` — nie przecinkiem.

UPDATE public.topics t
   SET question_count = sub.cnt
  FROM (
    SELECT topic_id, COUNT(*)::int AS cnt
      FROM public.questions
     WHERE topic_id = 'ZAR-01'
     GROUP BY topic_id
  ) sub
 WHERE t.id = sub.topic_id;
```

### Krok 2 — po każdym batchu

Uruchom `UPDATE` licznika `question_count` dla dotkniętego `topic_id` (jak wyżej).

Dla wielu tematów naraz możesz użyć:

```sql
UPDATE public.topics t
   SET question_count = COALESCE(sub.cnt, 0)
  FROM (
    SELECT topic_id, COUNT(*)::int AS cnt
      FROM public.questions
     WHERE topic_id LIKE 'ZAR-%' OR topic_id LIKE 'PRZ-%'
     GROUP BY topic_id
  ) sub
 WHERE t.id = sub.topic_id;
```

### Krok 3 — checklista

- [ ] `id` unikalne, małe litery, format `zar-NN-NNN` / `prz-NN-NNN`
- [ ] `topic_id` dokładnie jak w tabeli powyżej (`ZAR-01`, `PRZ-15`, …)
- [ ] `correct_option_id` ∈ {`a`,`b`,`c`,`d`,`e`}
- [ ] Apostrofy w tekście podwojone (`''`)
- [ ] Po imporcie: UPDATE `topics.question_count`
